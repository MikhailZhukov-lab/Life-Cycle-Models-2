# Методологія розробки

Для лабораторної роботи використовується ітеративний підхід Agile. Він
продовжує підхід із лабораторної роботи № 1 і дає змогу перевіряти результати
невеликими завершеними частинами.

| Ітерація | Результат | Перевірка |
|---|---|---|
| Вимоги й дані | Технічне завдання, формули варіанта | Ручний розрахунок першого рядка матриці |
| Математичне ядро | Генератор і три розв'язувачі | Еталонний вектор, контрольні та модульні тести |
| Інтерфейс і анімація | Форма вводу, графіки, покрокове відтворення | Перевірка браузерних сценаріїв |
| Аналіз і документація | Метрики, графіки, README | Звірка результатів для шести систем |

Поділ на ітерації дає змогу окремо перевіряти числові обчислення та браузерне
відображення. Головні ризики — нестійкість обчислень, помилкові дані та
незбіжність ітерацій. Для них передбачені перевірки малого pivot, валідація
матриці, попередження про відсутність строгої діагональної переваги та
контроль ліміту ітерацій.

Коміти цього репозиторію згруповано за етапами, наведеними в README. Вони
створені під час підготовки репозиторію й не датують первинне виконання кожної
частини роботи.
